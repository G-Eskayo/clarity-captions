# Seal Marketing Site

This directory contains the static marketing site for Seal, the free live-captioning app.

## Local preview

Open `index.html` directly in your browser (no build step required).

## GitHub Pages deployment

This folder is set up for GitHub Pages deployment via the `/site` directory path, which requires a one-time repository settings change:

1. Go to Settings → Pages
2. Select "Deploy from a branch"
3. Choose `main` branch, `/site` folder
4. Save

## Future

This site is currently committed within the clarity-captions repository. It can be trivially split into a separate `G-Eskayo/seal-site` repository if needed later.
