## Pass criteria (check §7 in ADR 0025)

1. **Battery drop:** Parakeet ≤ 1.3 × Apple's AND ≤ 15% per hour
2. **Thermal:** never `.critical`; if `.serious` appears, hop doubling must hold it there
3. **Energy attribution:** signpost intervals present and keyed by (subsystem, category)

## Fail criteria

1. `.critical` thermal state at any point
2. Battery drop > 1.5 × Apple's
3. Drop > 15% per hour
4. Zero signpost intervals (build without instrumentation)

## If test fails

If battery or thermal criteria are not met:
1. Re-run C2 (latency) to confirm 4-bit swap didn't regress decode p95
2. Try 4-bit variant: `VARIANT=ultra-pal4` in `scripts/fetch-asr-models.sh`
3. Re-run C3-C5 on 4-bit
4. If 4-bit also fails: decision D1 (Gil decides with numbers in view)

## Dependency failures (expected, not test failures)

If any of these are missing, the test is **not a test failure** but a blocker; the result is reported as "unavailable":

- **Zero signpost intervals:** older build without instrumentation
  - Report: `"component_split": "unavailable"`
  - Action: rebuild with commit [hash] or later
  
- **No comparable beta data:** beta report missing `dropPercentPer30Min`
  - Report: `"status": "no_comparable_data"`
  - Action: ensure beta report was sent from the same run

## Discards (data not usable, not a test failure)

- **Charging active:** xctrace window includes a charge event
  - Report: `"status": "discarded", "reason": "charging_active"`
  - Action: re-run with full battery cycle (80–90% start only)

- **Low Power Mode active:** device's low power mode flag set
  - Report: `"status": "discarded", "reason": "low_power_mode"`
  - Action: disable Low Power Mode before run

- **Start charge outside range:** initial battery level not 80–90%
  - Report: `"status": "invalid", "reason": "start_charge_outside_80_90"`
  - Action: re-run, starting with battery exactly at 80–90%

- **Display energy near zero:** screen was locked/dimmed during significant stretch
  - Report: `"status": "invalid", "reason": "display_energy_near_zero"`
  - Action: re-run with screen on throughout

## Notes

- Both engines are measured on the same phone in the same build (not separate runs)
- Re-running the script on the same inputs is idempotent
- xctrace and beta report must name the same engine (mismatch raises an error)
- Device model must be recognized (SE 3rd gen or 17 Pro; add more as needed)
