# Spec: From/Into language behavior in every case

## What From and Into are
- **From**: the language captions are made in, or being translated from (caption language, #37). Tapped in Settings opens the caption-language list; a pick that isn't on the device downloads first. Read from `CaptionLanguageSwitch.phase` and `CaptionLanguageCenter.change` (#37, CaptionLanguageCenter.swift).
- **Into**: the language captions are translated into (translation target, #53). Tapped in Settings opens the translation-target list; picks are available immediately (downloads happen in Settings, #245, #251). Read from `TranslationCenter.target` (TranslationCenter.swift).
- **Same language allowed** (#252, ADR 0031): From and Into can be the same language. When they match, `TranslationTargetList.rows()` filters out the caption language (CaptionLanguage.swift:219) so Into's list never shows it. When selected anyway (e.g., via direct API call or debug), `TranslationCenter.refreshConfiguration()` sets a configuration with source = target, which Apple's Translation framework does not support—the app will show `unsupportedPair = true` and translation becomes inactive until Into changes.
- **Captions follow the engine** (#37, CaptionLanguageSwitch): captions keep the old language until the new one's speech files are on the device. A failed download changes nothing.

## North star (owner's rule, #245)
Nothing in a feature starts a download. All language setup happens in Settings first. Every feature only offers ready combinations (installed caption language, installed translation pair, installed speech for translation).
